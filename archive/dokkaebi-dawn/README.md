# 동트기 3분 전 (Dokkaebi Dawn)

> 당신은 밤 산사(山寺)의 마지막 파수꾼. 동이 트는 3분 후까지 도깨비 무리로부터 살아남으세요.

인기 3D 게임들(Vampire Survivors, Risk of Rain 2, Hades, 젤다의 전설, Fortnite, Subway Surfers 등)의
검증된 재미 요소를 분석해 하나로 압축한 **브라우저 3D 호드 액션 프로토타입**입니다.
Three.js 프리미티브 지오메트리와 WebAudio 신스만 사용 — 외부 에셋이 전혀 없습니다.

## 실행 방법

로컬 서버로 정적 파일을 서빙하면 됩니다 (ES 모듈이라 `file://`로는 열 수 없습니다):

```bash
# 아무거나 하나 선택
npx serve .
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` (또는 표시된 주소)을 열면 끝. 빌드 과정 없음, 의존성 설치 없음.

## 조작법

| 입력 | 동작 |
|---|---|
| `W A S D` | 이동 |
| 마우스 | 조준 — 빛살이 **자동 발사**됩니다 |
| 좌클릭 | **벽력일섬** — 부채꼴 5연발 수동 일격 (쿨 2.5초) |
| `Shift` / `Space` | 대시 — 0.35초 무적, 적을 스치면 "아슬아슬!" 콤보 보너스 |
| `R` | 즉시 재시작 (1초 이내) |
| `ESC` | 일시정지 |
| `1` `2` `3` | 레벨업 카드 선택 |

디버그: `0` 10배속 토글 · `9` 통계 오버레이 · `8` 무적 (사용 시 기록 비활성화)

## 게임의 뼈대

- **3분 하드캡** — 하늘의 붉은 달이 가라앉는 것이 곧 시계이자 위협 게이지. 3:00에 동이 트면 승리.
- **자동 발사 + 수동 한 방** — 이동과 조준에 집중하는 VS식 편안함 위에, 좌클릭 벽력일섬의 방아쇠 감각.
- **20~25초마다 레벨업** — 일반/희귀/영웅 등급이 굴려지는 3장의 카드에서 무기 6종 + 패시브 4종을 조합.
- **진화 잭팟** — 회전 부적 Lv.5 + 도깨비 방망이 보유 시 '팔괘진' 진화 확정 등장.
- **타임라인 이벤트** — 1:00 포위 링 → 1:30 황금 보급 궤짝 → 2:00 미니보스 어둑시니 → 2:30 광란 → 2:50 최종 쇄도 → 3:00 일출.
- **죽어도 전진** — 패배해도 엽전과 미션 진행을 지급. 엽전 상점(영구 강화), 미션(기본 배율 +1), 밤 반복(난이도 사다리), 점수 스킨 해금.

## 프로젝트 구조

```
index.html      — HUD·화면·스타일 (전부 한국어 UI)
src/main.js     — 게임 엔진: 지형, 적 군단, 무기, 스폰 디렉터, 주스, 메타
src/config.js   — 모든 밸런스 상수 (난이도 노브는 coeff 식 하나)
src/audio.js    — WebAudio 신스 SFX (오음계 픽업 사다리 포함)
src/ui.js       — DOM HUD 컨트롤러
lib/three.module.js — Three.js r185 (번들, 오프라인 동작)
docs/DESIGN.md  — 인기 게임 분석 → 설계 결정 근거 문서
```

## 성능 설계

- 적 최대 600기 동시 생존: 타입별 `InstancedMesh` (도깨비 몸통+뿔 병합 지오메트리)
- 파티클 1024개 링버퍼 `InstancedMesh` 1드로우콜
- 공간 해시(셀 2u)로 충돌·분리·범위 판정 — 시뮬 루프 내 할당 없음
- 그림자 맵 없음 (블롭 섀도) · 안개+반구광 저비용 분위기 · 고정 타임스텝 60Hz
