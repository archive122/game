# 게임 디자인 문서 — 동트기 3분 전 (Dokkaebi Dawn)

이 문서는 인기 3D 게임 7개 영역(오픈월드 액션, 슈터/배틀로얄, 샌드박스/복셀, 캐주얼 아케이드,
로그라이트 서바이버, 게임필/주스, Three.js 기술)을 분석한 뒤, 3개의 독립 컨셉 경쟁과
3인 심사(게임필 순수주의자 / 라이브옵스 분석가 / 실용주의 테크리드)를 거쳐 만장일치로 선정된
최종 설계안입니다.

## 피치

당신은 밤 산사(山寺)의 마지막 파수꾼. 어둠 속에서 도깨비 떼가 밀려오고, 손의 빛의 탄환은 마우스가 가리키는 곳으로 쉬지 않고 자동 발사된다. 좌클릭 한 번이면 '벽력일섬' — 반동과 섬광이 손끝에 꽂히는 수동 일격이 포위망을 찢는다. 하늘의 붉은 달이 부풀수록 위협이 커지고, 달이 창백해지며 지평선으로 가라앉을수록 새벽이 가깝다. 해야 할 일은 단 하나, 동이 트는 3분 후까지 살아남는 것. 도깨비를 터뜨려 쏟아지는 도깨비불(XP)을 도레미 상승 음계로 빨아들이고, 20여 초마다 일반·희귀·영웅 등급이 굴려지는 셋 중 하나의 카드를 골라 회전 부적과 지면 파동으로 화면을 가득 채우는 신이 되어라. 1:30 황금 보급 궤짝이 빛기둥을 타고 내려와 안전한 궤도를 이탈시키고, 2:00 어둑시니가 땅을 울리며, 마지막 30초 '가장 어두운 새벽'에는 심장박동이 화면을 조인다. 죽으면 캐릭터가 코믹하게 조각나 튀고, "새벽까지 0:14"라는 아쉬움과 함께 R 키 한 번이면 1초 안에 다시 밤이 시작된다. 튜토리얼 없음, 로딩 없음 — 시작 3초 안에 첫 킬, 10초 안에 첫 카드, 3분 안에 완결되는 권능의 서사. 한 판만 더. 이번엔 새벽을 볼 수 있을 것 같으니까.

## 디자인 필러

- 시간 압축의 서사 — 3초 안에 첫 킬, 10초 안에 첫 카드, 20~25초마다 보상, 3분 안에 완결. 모든 시스템 수치는 이 리듬표를 어기지 않는다.
- 정보는 세계 안에 — 붉은 달이 위협(스폰 계수)이고 가라앉는 달이 시계이며, 등불의 빛 웅덩이가 안전지대다. HUD는 숫자 확인용, 상황 판단은 화면 그 자체로 한다.
- 재시작이 죽음보다 싸다 — 사망 연출 0.5초, R 키에서 조작 가능까지 1.0초 이내, 리로드 없음. 패배도 엽전과 미션 진행을 지급해 빈손 런이 없다.
- 화력은 폭주, 생존은 수렴 — 피해/연사/투사체는 선형·무제한 스택으로 신이 되게 하고, 슬로우·감쇠·회복은 상한이 있어 무적은 불가능하다. 압력과 권능이 끝까지 경주한다.
- 모든 입력에 3중 피드백 — 시각(플래시·파티클·셰이크) + 청각(레이어드 신스) + 시간(히트스톱·슬로모)이 같은 프레임에 겹치지 않는 이벤트는 존재하지 않는다.

## 코어 루프

WASD로 무리를 카이팅하며 마우스로 겨누면 빛살이 자동으로 불을 뿜고, 좌클릭 '벽력일섬'(쿨 2.5초)은 반동·머즐 플래시·히트스톱이 방아쇠에 직결된 수동 부채꼴 일격으로 포위를 찢는다. 도깨비가 터질 때마다 히트스톱·백색 섬광·자기 색 조각 파티클·타격음이 겹치고, 죽은 자리에 도깨비불(XP 젬)이 남는다. 청소한 지역으로 되돌아 들어가 젬을 진공청소기처럼 빨아들이면 픽업마다 한 음씩 올라가는 오음계 사다리가 울린다 — 수집 자체가 콤보다. Shift 대시(0.35초 무적)로 적을 0.5유닛 이내로 스치면 '아슬아슬!' 보너스로 콤보 게이지가 연장된다. 20~25초마다 레벨업 → 게임 정지 → 일반/희귀/영웅 등급이 굴려진 셋 중 하나의 한국어 카드 선택 → DPS 미터가 눈에 띄게 폭등하며 화면이 더 시끄러워진다. 스폰 디렉터는 단일 시간 계수로 예산을 늘리며 1:00 포위 링, 1:30 황금 보급 궤짝(영웅 카드 확정, 위험 동선 강제), 2:00 미니보스 어둑시니, 2:30 광란, 2:50 최종 쇄도를 투하한다. 하늘의 붉은 달은 계수에 비례해 붉어지고 시간에 비례해 가라앉는다. 3:00 일출 — 하늘이 주황으로 물들며 남은 도깨비 전원이 재로 흩어지는 승리, 또는 그 직전에 죽어 "새벽까지 0:14"라는 근소한 아쉬움과 함께 즉시 R.

## 인기 게임 차용 맵 — 어떤 기능이 어느 게임에서 왔는가

- 자동발사 + XP 젬 진공 + 20초 주기 1/3 카드 + 무기 진화(팔괘진) ← Vampire Survivors (약 23초당 1회의 보상 밀도와 슬롯 캡 강제 트레이드오프가 장르의 검증된 심장)
- 단일 시간 계수 + 크레딧 예산 스폰 디렉터 + 정예 6배 비용 ← Risk of Rain 2 (노브 1개로 전체 곡선이 파생되어 한 자리 튜닝 가능 — 최대 리스크 완화)
- 화력 선형·무제한 / 방어 수렴 스택 수학 ← Risk of Rain 2 (공격 폭주는 판타지, 방어 100%는 금지)
- 카드 희귀도 롤(일반/희귀/영웅 + 금색 플러리시) ← Hades (매 선택에 슬롯머신 기대감, 약 30줄 비용)
- 벽력일섬 수동 트리거 + 사수 반동 + 1프레임 머즐 플래시 ← Nuclear Throne / Vlambeer 'Art of Screenshake' (자동발사가 버리는 방아쇠 감각을 단일 입력으로 복원)
- 대시 무적 프레임 + 3D 이동 스킬 천장 ← Elden Ring 회피 굴리기 / Megabonk (탑다운 원작에 없는 마스터리 축)
- 아슬아슬 니어미스 보너스 ← Subway Surfers 니어미스 심리 (수동적 아까움을 능동 기술 보상으로 전환)
- 1초 재시작 + 코믹 조각 사망 ← Crossy Road / Fall Guys ('졌을 때 기분 나쁘지 않게' — 죽음이 구경거리면 R은 반사신경이 된다)
- 보급 궤짝 + 가시 빛기둥 ← Warzone/Fortnite 서플라이 드롭 (예정된 분쟁 자석으로 제자리 궤도 카이팅 파훼)
- 3:00 하드 타임캡과 일출 클라이맥스 ← Vampire Survivors 30:00 사신의 반전 (죽음의 마감이 아니라 구원의 마감 — 같은 목표 구배, 반대 감정)
- 가라앉는 붉은 달 = 다이제틱 위협·시간 게이지 ← Zelda: Majora's Mask의 달 + BotW식 'UI 없는 정보' 원칙 (위협과 희망을 HUD 비용 0으로 동시 전달)
- 등불 빛 웅덩이 = 빛으로 영역 주장 ← Minecraft 횃불 문법 (조명이 곧 진행도·안전 지도, 정예의 소등이 상실 이벤트)
- 미션 3종 로테이션 → 영구 기본 배율 +1 ← Subway Surfers 미션-배율 시스템 (사망 화면을 다음 런의 목표 게시판으로)
- 엽전 영구 상점 + 밤 반복 난이도 사다리 ← Vampire Survivors PowerUps + Hades 열기(Heat) (패배도 전진하는 랫칫)
- 도깨비불 픽업 상승 오음계 사다리 ← Peggle의 상승 음계 보상 문법 (수집 스윕 자체가 청각 콤보)
- 멀티킬 슬로모 + FOV 킥 ← DOOM(2016)/ULTRAKILL 하이라이트 저작 (화면 청소 순간을 몸으로 느끼는 시간 보상으로)
- 실시간 DPS 미터 + 킬 카운터 ← Deep Rock Galactic: Survivor (카드 픽 직후 수치 폭등 = 성장 판타지의 수치적 증명)
- 행동 어픽스 정예(불덩이 화염 궤적 / 서리 슬로우) ← Risk of Rain 2 Blazing/Glacial 엘리트 (색+스케일 정예보다 체감 다양성이 배가되는 행동 변형)
- 최종 30초 '가장 어두운 새벽' 심장박동 크레셴도 ← Left 4 Dead 피날레 호드 문법 (일출 카타르시스 앞에 공포의 정점을 저작)
- 히트스톱·trauma² 셰이크·스쿼시&스트레치·영속 잔해 ← Vlambeer + 'Juice it or Lose it' + Eiserloh GDC (프리미티브 아트를 대체하는 3중 피드백 스택 전체)

## 조작

WASD — 이동 · 마우스 — 조준(빛살 자동 발사, 포인터락 불필요) · 좌클릭 — 벽력일섬(부채꼴 5발 수동 일격, 쿨 2.5초) · Shift 또는 Space — 대시(0.35초 무적, 쿨 2.5초) · R — 즉시 재시작(1초 내) · ESC — 일시정지 · 레벨업 카드 — 마우스 클릭 또는 1/2/3 · 디버그: 0 = 10배속, 9 = 통계 오버레이, 8 = 무적. 배워야 할 것은 '움직이고, 겨누고, 가끔 좌클릭' — 시작 화면 하단 한 줄이면 충분: "WASD 이동 · 마우스 조준 · 좌클릭 벽력일섬 · Shift 대시"

## 비주얼 방향

'단청 네온 민화' — 배경과 안개가 같은 짙은 남색 #1a1a2e로 세계가 하늘에 녹아들고(Fog 26→88), flatShading 프리미티브가 달빛 DirectionalLight(#b0c4ff, 1.2)와 HemisphereLight(#3a3a5e/#16162a, 0.7) 아래 실루엣으로 읽히는 밤 산사. 지형은 심플렉스 완만 구릉에 높이 밴딩 정점색 #23233d→#2e2e52. 도깨비는 단청 팔레트의 뿔 달린 박스 — 잡몹 주홍 #e84545, 혼불 청록 #4dd8e6(0.7 스케일·부유 바운스), 탱커 황토 #c98a3d(1.5 스케일), 정예는 어픽스 색 emissive(불덩이 #ff5b22 화염 궤적 / 서리 #7fb8ff) + 1.6배 + 트레일. 도깨비불 XP는 청백 #aef1ff 발광 옥타헤드론, 플레이어 탄환은 과장되게 큰 금색 #ffd166 스트레치 트레이서, 벽력일섬은 5줄기 부채꼴 섬광. 석등 6기의 PointLight(#ffb04d, 강도 3, 거리 12)가 어둠 속 안전 웅덩이를 점점이 밝히고, 소등되면 웅덩이가 꺼져 상실이 즉각 보인다. 하늘의 달(반경 6 emissive 스피어)은 스폰 계수에 비례해 흰색→핏빛 #ff4444로 물들며 3분에 걸쳐 지평선으로 가라앉는 다이제틱 위협·시간 게이지 — 안개색에 달 색이 10% 블렌드되어 밤 전체가 서서히 붉어진다. 2:30 이후 하늘은 #12101f까지 침강했다가 3:00 승리 시 8초에 걸쳐 지평 #ff9a3c·상공 #ffd9a0의 새벽으로 lerp되는 일출이 유일한 컷신. 그림자 맵 없이 블롭 섀도(검정 원, opacity 0.35), 모든 것은 프리미티브 + 조명 + 안개 + InstancedMesh 파티클 — 드로우콜 50 미만으로 인텔 내장 GPU 60fps.

- 대시 — 화이트노이즈 스위프 150ms(하강 필터)

- 카드 선택 — 확정 stamp 톤 / 영웅 등급 등장 — 전용 3음 금빛 팡파르 + 반짝임
