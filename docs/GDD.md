# 잿불의 결투: 몰락한 파수꾼 — 게임 디자인 문서 (GDD)

> 무너진 대성당, 달빛 갓레이 아래에서 8m 석상 거인 "잿불 파수꾼"과 벌이는
> 단 한 번의 소울라이크 결투. 브라우저에서, 외부 에셋 없이, 언리얼 엔진의 룩으로.

## 0. 기획 프로세스

본 기획은 4개의 독립 컨셉(보스 시네마틱 / 분위기 어드벤처 / 아레나 슈터 / 다크 판타지 핵앤슬래시)을
서로 다른 관점의 심사위원 3명(비주얼 임팩트 / 게임 디자인 / 테크 리드)이 교차 심사해 선정했다.

| 컨셉 | 비주얼 | 재미 | 실현성 | 종합 |
|---|---|---|---|---|
| **잿불의 결투: 몰락한 파수꾼** | **1위** | 2위 | **1위** | **우승** |
| 낙조의 콜로세움 | 3위 | 1위 | 3위 | 2위 |
| 혈월 신전: 잿불의 기사 | 4위 | 3위 | 2위 | 3위 |
| 낙일(落日)의 거신 | 2위 | 4위 | 4위 | 4위 |

**우승 근거** — ① 어두운 밤 장면은 절차적 텍스처의 약점을 가리고 HDR 발광+블룸이 가장 "언리얼답게"
빛나는 조합(비주얼 심사평: 사실상 언리얼 Elemental 데모의 절차적 재구성). ② 아트 예산 전부가
단일 아레나에 집중되어 화면당 밀도 최고. ③ 화면 속 캐릭터 2체(그중 1체는 석상)로 절차적
애니메이션 결함 노출 면적 최소. ④ 콘텐츠가 "아레나 1 + 보스 1"뿐이라 스코프 표면적이 가장 작고,
패턴은 공통 상태기계 + 데이터 테이블로 구동되어 완성 확률 최고.

**탈락 컨셉에서 이식한 아이디어** — 리프트/감마/게인 색 그레이딩, 높이 안개(onBeforeCompile 주입),
섀도 카메라 텍셀 스냅, 킬캠+레터박스 시네마틱, ConvolverNode 절차적 리버브, 피격 emissive 백색 점등,
판정-비주얼 디커플링, scaledDelta/rawDelta 단일 클록, 전면 오브젝트 풀링, 구르기 잔상 고스트,
사인파 3개 합성 횃불 플리커, 페이즈 연동 적응형 BGM, 연속 사망 소프트 이지모드, 사망 화면 패턴명 표기.

**첫 30초 개선(재미 심사 지적 반영)** — 별도 진입 회랑을 없애고, 아레나 입구 바닥의 한국어 각인으로
조작을 디에제틱하게 안내. 보스는 빛기둥 아래 무릎 꿇은 채 대기하다 접근 시 각성 시네마틱(3초) 후
즉시 결투 개시. 재도전은 각성 연출 없이 1초 만에 전투 재진입.

## 2. 코어 루프 (30초 단위)

1. **관찰 (0~10s)** — 모든 보스 패턴은 0.55초 이상의 이중 텔레그래프(무기/몸 발광 + 패턴별 고유 신스 음색)를
   가진다. 록온 스트레이프로 "이번엔 뭐가 오는가"를 읽는다.
2. **회피와 응징 (10~20s)** — 구르기(무적 0.30초, 스태미나 25)로 흘리고, 패턴별로 명시된
   후딜 창(0.8~2.0초)에 약공 콤보나 강공을 꽂는다. 욕심내면 다음 패턴에 맞는다 —
   **"한 대 더 칠까?"의 긴장이 루프의 심장.**
3. **자원 관리 (20~30s)** — 스태미나(100, 초당 35 회복, 고갈 시 1초 탈진)로 공격/회피를 배분하고,
   위험하면 거리를 벌려 플라스크(3회, 시전 1.2초 경직)를 마신다. 강공·후딜 punish는 그로기
   게이지를 빠르게 채우고, 만충 시 5초 무방비 + 크리티컬 처형(3배 대미지 + 오빗 킬캠)이 열린다.

죽으면 남는 성장 자원은 **패턴 지식**뿐 — 순수 소울라이크 재도전 루프.

## 3. 게임 구조

```
타이틀(안개 성당 오빗 시네마틱) → 입장(바닥 각인 튜토리얼, 자유 이동)
  → 보스 각성(레터박스 3초) → 1페이즈 → 2페이즈(붕괴 연출) → 3페이즈(검 점화)
  → 승리(킬캠+비문 엔딩+통계) / 패배(사인 패턴명 + 3초 재도전)
```

- **1페이즈 「심판」 (HP 100~65%)** — 기본 패턴 4종. 느리고 읽기 쉬운 "가르치는 페이즈".
- **2페이즈 「각성」 (HP 65~30%)** — 기둥 붕괴 + 남색→진홍 전역 라이팅 크로스페이드(2초).
  신규 패턴 3종 + 기존 패턴 속도 15% 상승 + 페인트(멈칫 후 발동) 도입.
- **3페이즈 「잿불」 (HP 30~0%)** — 대검 점화. 광역 패턴 2종 추가 + 이동속도 상승. 짧고 격렬한 클라이맥스.
- **패배** — "그대는 재가 되었다" + 직전 피격 패턴명 표기. R 또는 클릭으로 즉시 재도전(풀 리셋만, 재로딩 없음).
  연속 5회 사망 시 소프트 이지모드 **"잿불의 가호"**(받는 피해 -15%) 제안.
- **승리** — 슬로모 킬캠 → 잿불 낙하 → 비문(碑文) 에필로그 → 통계(클리어 타임 / 피격 횟수 / 회피 성공률 / 노히트).

## 4. 전투 설계

### 조작
| 입력 | 동작 |
|---|---|
| `W A S D` | 카메라 기준 이동 |
| 마우스 | 시점 (포인터락) |
| 좌클릭 | 약공 3타 콤보 (타당 스태미나 15, 선입력 버퍼 0.2초) |
| 우클릭 | 강공 (차지 가능, 스태미나 35, 그로기 축적 2.5배) |
| `Space` / `Shift` | 회피 구르기 (무적 0.30초, 스태미나 25) — 공격 후반부 캔슬 가능 |
| `Q` / 휠클릭 | 록온 토글 |
| `E` | 회복 플라스크 (3회, 최대 HP 45%, 1.2초 경직) — 그로기 보스 근접 시 처형 |
| `R` | (사망/승리 화면) 재도전 |

### 플레이어 자원
- HP 100 / 스태미나 100 (초당 35 회복, 액션 후 0.4초 회복 지연, 0 도달 시 1초 탈진)
- 그로기 게이지(보스): 약공 +6, 강공 +15, **후딜 창 타격 1.5배**, 초당 -4 자연 감소

### 보스 패턴 9종 (전부 데이터 구동: 텔레그래프→발동→후딜 공통 상태기계)
| # | 패턴 | 텔레그래프 | 회피 해법 | 후딜 창 |
|---|---|---|---|---|
| P1 | 3연 횡베기 | 어깨 발광 0.7s | 뒤/옆 구르기 | 1.6s |
| P2 | 내려찍기 | 대검 머리 위 0.9s | 충격파 링 밖으로 | 2.0s |
| P3 | 붙잡기 돌진 | 낮은 자세 + **붉은 발광** 0.8s | 옆구르기 한정 | 1.8s |
| P4 | 밟기 | 0.6s (근접 견제) | 이탈 | 0.9s |
| P5 | 화염 분출 (2P~) | 바닥 데칼 링 3개 순차 0.8s | 링 밖 | 1.4s |
| P6 | 도약 강타 (2P~) | 발밑 데칼 1.0s | 착지 직전 구르기 | 1.9s |
| P7 | 페인트 베기 (2P~) | P1과 동일 예비동작 + 0.4s 멈칫 | 늦은 구르기 | 1.6s |
| P8 | 검기 파동 (3P~) | 수평 자세 0.7s | 옆구르기 | 1.5s |
| P9 | 잿불 폭우 (3P~) | 낙하 데칼 0.7s × 8 | 지속 이동 | — |

**페어니스 규칙** — 시각+청각 이중 텔레그래프, 잡기만 붉은색, 화면 밖 공격은 반드시 바닥 데칼 예고,
사망 화면에 패턴명 표기. "죽어도 내 탓" 문법.

**판정-비주얼 디커플링** — 충격파=확산 링 반경 검사, 베기=부채꼴 각도 검사, 돌진=캡슐 스윕.
판정은 전부 프리미티브 수학, 메시는 연출 전용.

## 5. 언리얼 룩 — 렌더링 설계

| 기법 | 구현 |
|---|---|
| HDR 파이프라인 | 씬을 HalfFloat 타깃에 선형 렌더 → 블룸 → 최종 합성 셰이더에서 ACES 필믹 톤매핑 (노출 1.1) |
| 블룸 | UnrealBloomPass 방식 자체 구현: 브라이트 패스(임계 1.0) + 5레벨 밉 가우시안 + 가중 합성. HDR emissive(2~8)만 빛남 |
| PBR + 환경 반사 | 절차적 미니 씬(그라디언트 하늘+발광 쿼드)을 PMREM으로 구움. 갑옷/검 metalness 0.9 / roughness 0.25 |
| 동적 그림자 | 달빛 DirectionalLight 1개, 2048 PCFSoft, 아레나 40m 타이트 절두체, bias -0.0004, **텍셀 스냅**으로 시머링 제거 |
| 볼류메트릭 분위기 | FogExp2(남색 0.022) + **높이 안개 onBeforeCompile 주입** + 갓레이 프레넬 원뿔 + 부유 먼지/잿불 Points |
| 검광 트레일 | 칼끝/손잡이 링버퍼 → 리본 지오메트리, UV 나이 알파 페이드, 가산 블렌딩, HDR 색 |
| 포스트 체인 | 단일 합성 패스: ACES + **리프트/감마/게인 그레이딩** + 비네트 + 필름 그레인 + 방사형 색수차 + 피격 적색 맥동. 이후 FXAA |
| 시네마틱 카메라 | 스프링암 지수 감쇠 추적, 록온 Furi식 프레이밍, trauma² 노이즈 셰이크, FOV 킥, 오빗 킬캠 + 레터박스 |
| 게임필 | 히트스톱(약 70ms/강 140ms/처형 200ms), 슬로모(막타 0.1×), 피격 emissive 백색 점등, 구르기 잔상 고스트, 풀링 PointLight 플래시 |
| 페이즈 스펙터클 | 기둥 파편 의사 물리 붕괴 + 전역 라이팅/포그/환경 강도 2초 크로스페이드 + 잿불 800개 부유 |

**색 팔레트** — 1페이즈: 심연 남색 `#0B1220` / 점판암 `#5A6472` / 월광 청백 `#BFD9FF` / 화로 주황 `#FF6A00`.
2~3페이즈: 포그 암적색 `#2A0E08` + 키라이트 잿불 주황 `#FF7A2E`. 청백은 플레이어 검광 전유색 —
아군/적군 색 언어 분리. 채도는 낮게, 발광만 HDR로.

**조명** — 키(달빛, 유일한 섀도 캐스터) + 필(HemisphereLight 0.4) + 악센트(화로 PointLight 4개,
사인파 3개 합성 플리커) + 림(프레넬 림라이트). 총 라이트 7개 이하.

## 6. 아레나 (직경 40m 원형 성소)

절반쯤 붕괴한 돔 천장의 구멍으로 달빛 갓레이가 쏟아지고, 외곽은 부러진 열주 링,
그 너머는 안개 소실. 시선은 항상 "보스 + 빛기둥 + 실루엣 기둥"의 삼단 구도.

절차적 소품: 도리아식 기둥 12기(세로 홈 노멀맵, 랜덤 파단면) / 파괴용 사전 분할 기둥 /
무너진 아치 / 바닥 석판(Canvas: 줄눈+노이즈 얼룩+랜덤 워크 균열, albedo/roughness 이중 활용) /
중앙 제단(발광 룬) / 배경 거신상 실루엣 / 화로 4기 / 찢어진 배너(버텍스 셰이더 바람) /
연마 방패(metalness 1.0 / roughness 0.05 — envMap 쇼케이스) / 부유석 파편.
드로우콜 목표 80 이하, 텍스처는 전부 Canvas 절차 생성(펄린 노이즈/랜덤 워크/그라디언트 3원소).

## 7. 오디오 (WebAudio 신스)

- SFX: 휘두름=필터 스윕 노이즈, 타격=저역 붐+디스토션, 구르기=우퍼 펄스,
  패턴별 고유 텔레그래프 음색(오디오 큐만으로 회피 가능한 수준).
- 공간감: 절차 생성 임펄스 응답 + ConvolverNode 리버브(대성당 잔향).
- BGM: 드론 → 퍼커션 → 리드 순차 적층되는 페이즈 연동 적응형 2트랙.

## 8. 엔지니어링 규율

- **단일 클록** — `gameDelta = rawDelta × timeScale`. 히트스톱/슬로모는 timeScale만 조작.
  카메라 셰이크·UI·포스트FX·BGM은 rawDelta 구동 (1일차 확립).
- **런타임 할당 금지** — 파티클/데칼/투사체/플래시 전부 풀링. 재도전은 풀 리셋만.
- **품질 자동 조정** — 롤링 평균 FPS 감시 → 그림자 1024 → 색수차·FXAA 오프 → 파티클 절반의 3단 강등.
- **TUNING 단일 상수 객체** — 모든 게임필/전투 수치를 `config.js`에 집중.
- **디버그 키** — `8` 무적, `9` 통계, `0` 배속, `7` 보스 그로기, `6` 페이즈 스킵.
- 픽셀비 상한 1.5, 블룸 1/2 해상도, 섀도 캐스터 1개.
