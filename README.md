# 잿불의 결투: 몰락한 파수꾼 (Duel of Embers)

> 무너진 대성당, 달빛이 쏟아지는 성소. 8m 석상 거인 **잿불 파수꾼**과의 단 한 번의 결투.
> 죽고, 배우고, 다시 도전하라 — 유일한 성장 자원은 **패턴 지식**이다.

**언리얼 엔진의 룩**을 목표로 브라우저에서 절차적으로만 구현한 **소울라이크 1:1 보스 결투 액션**입니다.
3D 모델·텍스처·사운드 파일이 전혀 없습니다 — 지오메트리는 코드, 텍스처는 Canvas, 소리는 WebAudio 신스로 태어났습니다.

## 실행 방법

정적 서버로 서빙하면 끝입니다 (ES 모듈이라 `file://`로는 열 수 없습니다):

```bash
npx serve .            # 또는
python3 -m http.server 8000
```

브라우저에서 표시된 주소를 열고 **결투 시작**. 빌드 없음, 설치 없음, 네트워크 요청 없음.

## 조작법

| 입력 | 동작 |
|---|---|
| `W A S D` | 이동 (카메라 기준) |
| 마우스 | 시선 (포인터락) |
| 좌클릭 | 약공 — 3타 콤보 (선입력 버퍼 0.2초) |
| 우클릭 꾹 | **강타 차지** — 풀차지 시 충격파, 그로기 축적 2.5배 |
| `Space` / `Shift` | **구르기** — 무적 0.3초. 공격 후반부 캔슬 가능 |
| `Q` | 록온 (Furi식 보스 프레이밍) |
| `E` | 성수 플라스크 (3회, 시전 1.2초) / 그로기 보스 근접 시 **처형** |
| `R` | (사망/승리 화면) 즉시 재도전 |
| `M` | 소리 켜기/끄기 |

디버그: `8` 무적 · `9` 통계 · `0` 배속 · `7` 보스 그로기 · `6` 페이즈 스킵

## 게임의 뼈대

- **관찰 → 회피 → 응징의 30초 루프.** 모든 패턴은 0.55초 이상의 이중 텔레그래프
  (무기 발광 + 패턴별 고유 신스 음색)를 가지며, 패턴마다 명시된 후딜 창(0.8~2.0초)이 응징 타이밍이다.
  욕심내면 다음 패턴에 맞는다 — "한 대 더 칠까?"의 긴장이 루프의 심장.
- **스태미나가 심판자.** 공격 15/35, 구르기 25. 고갈 시 1초 탈진. 회복 플라스크는 1.2초 경직을 동반한다.
- **그로기 → 처형.** 후딜 창 타격은 그로기 1.5배. 게이지 만충 시 파수꾼이 무너지고,
  `E` 처형으로 대미지 + 체력 회복 — 후퇴 대신 전진을 보상한다 (Doom 글로리킬 문법).
- **3페이즈 드라마.** 「심판」(가르치는 4패턴) → 「각성」(기둥 붕괴 + 남색→진홍 세계 전환 + 페인트 도입)
  → 「잿불」(검 점화 + 광역 패턴). 페이즈마다 BGM 레이어가 쌓인다 (드론 → 퍼커션 → 리드).
- **죽어도 내 탓.** 잡기만 붉게 빛나고, 화면 밖 공격은 반드시 바닥 데칼로 예고되며,
  사망 화면에 직전 피격 패턴명이 표기된다. 연속 5회 사망 시 소프트 이지모드 「잿불의 가호」 제안.

## 언리얼 룩 — 렌더링 파이프라인

씬을 **선형 HDR**(HalfFloat RT)로 렌더한 뒤 전 과정을 수동 제어합니다:

```
씬(선형 HDR) → 브라이트패스 → 5레벨 밉 가우시안 블룸(UnrealBloomPass 방식 자체 구현)
  → 합성: ACES 필믹 톤매핑 + 리프트/감마/게인 그레이딩 + 비네트 + 방사형 색수차 + 필름 그레인
  → FXAA → 화면
```

- **PBR + 절차적 환경 반사** — 미니 환경 씬을 PMREM으로 구워 갑옷·검·젖은 석재가 달빛을 반사
- **동적 그림자** — 달빛 DirectionalLight 1개(2048 섀도맵), 아레나에 타이트한 절두체
- **볼류메트릭 분위기** — FogExp2 + 전 머티리얼 **높이 안개 주입**(onBeforeCompile) + 갓레이 원뿔 + 부유 먼지
- **검광 리본 트레일** — 링버퍼 지오메트리, 나이 기반 알파 페이드, HDR 색으로 블룸 점화
- **게임필** — 히트스톱(70/140/200ms 차등), 처형·막타 슬로모, trauma² 카메라 셰이크, FOV 킥,
  구르기 잔상 고스트, 피격 시 적 emissive 백색 점등, 풀링 PointLight 플래시
- **단일 클록 규율** — `gameDelta = rawDelta × timeScale`. 히트스톱/슬로모는 timeScale만 조작하고
  카메라 셰이크·UI·포스트FX·BGM은 rawDelta로 구동
- **품질 자동 조정** — 롤링 FPS 감시로 픽셀비/그림자/FXAA 3단 강등

## 프로젝트 구조

```
index.html          — 화면·HUD DOM + 시네마틱 스타일 (전부 한국어)
src/main.js         — 부트스트랩 + 게임 흐름 상태기계 + 단일 클록
src/config.js       — TUNING 전 수치 + 보스 패턴 9종 데이터 테이블
src/renderer.js     — HDR 파이프라인·블룸·합성·FXAA·높이 안개·품질 거버너
src/arena.js        — 대성당: 하늘·열주·돔·화로·갓레이·룬 마법진·페이즈 팔레트
src/camera.js       — 스프링암·록온·trauma² 셰이크·킬캠·시네마틱
src/fx.js           — GPU 파티클 풀·트레일·충격파 링·텔레그래프 데칼·잔상
src/hero.js         — 기사 리그·키포즈 애니·전투 조작
src/boss.js         — 파수꾼 리그·패턴 상태기계·페이즈·투사체
src/audio.js        — WebAudio 신스 SFX·절차 리버브·적응형 BGM
src/ui.js           — DOM HUD 컨트롤러
lib/three.module.js — Three.js r185 (로컬 번들, 오프라인 동작)
docs/GDD.md         — 게임 디자인 문서 (기획 공모·심사 과정 포함)
```

## 기획 과정

이 게임은 4개의 독립 컨셉(보스 시네마틱 / 분위기 어드벤처 / 아레나 슈터 / 핵앤슬래시)을
비주얼·재미·실현성 3인 심사로 교차 평가해 선정하고, 탈락 컨셉의 강점(색 그레이딩, 높이 안개,
킬캠 레터박스, 절차 리버브, 소프트 이지모드 등)을 이식해 완성했습니다.
전체 기획서는 [docs/GDD.md](docs/GDD.md)를 참고하세요.
